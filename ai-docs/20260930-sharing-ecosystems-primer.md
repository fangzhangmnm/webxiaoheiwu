# 分享生态科普：稿子出门之后，会落在谁的什么设备上

> created 20260930 · by Claude Fable 5.1 (claude-fable-5-1) · as-of 2026-09-30
> 读者 = 在小黑屋里写完了东西、想给朋友看、但对各家平台不熟的作者。
> 内容来源 = 模型记忆（截止 2026 年中），平台规则一年一变；**标 ⚠ 的是我没把握的**，拿来做产品决策前要核。

## 0. 先说结论，后面是解释

你的稿子要出门，先过一道筛子：**朋友在手机上点一下，能不能直接看见**。能过这道筛的格式只有三种——**图片、PDF、纯文本**。其它一切（markdown 源文件、html、epub）在手机聊天软件里都要「用其他应用打开」，那一步就是绝大多数人放弃的地方。

三种格式各有各的去处：
- **长图** = 发在社交上、丢在群里「随手看一眼」的东西。适合短篇、单章、片段。
- **PDF** = 「一本书」在手机上唯一通用的样子。微信、QQ、iMessage、Discord、LINE 全都点一下就翻页。适合整本、中长篇。
- **纯文本** = 粘进各平台自己的编辑器（公众号、晋江、AO3、pixiv……）的原料；也是喂 AI、做备份的形态。（你自己说的：长文本直接贴在社交上不礼貌。）

各地区的差别不在格式上，在**「人在哪」**：墙内成年人在微信、年轻人在 QQ；西方在 Discord 和 iMessage；日本在 LINE 和 X。平台差别在**「认真发表去哪」**：墙内是公众号 / 晋江 / LOFTER，西方是 AO3 / Royal Road，日本是 pixiv / なろう / BOOTH。

## 1. 筛子：什么叫「点一下就能看」

聊天软件里收到一个文件，有两种命运。

**内联预览**：点一下，就在聊天软件自己的窗口里打开了，不跳出去、不装东西、不登录。微信、QQ、iMessage、Discord、Telegram、LINE 都对**图片、PDF、txt**做到了这一点（微信和 QQ 还多认 Word / Excel / PPT，因为腾讯自己有文档产品）。

**「用其他应用打开」**：点一下，弹出一个系统菜单问你想用什么打开。markdown（`.md`）、html、epub 都是这个命运。html 在微信里更惨：微信把它当潜在风险文件，很多时候连「用其他应用打开」都不给（⚠ 具体行为随版本变）。epub 在 iPhone 上稍好一点——系统自带的「图书」app 认它，所以 iPhone 用户点一下会进 Books；Android 没有系统级 epub 阅读器，得先装一个。

所以 html「不够手机友好」不是排版问题，是**它根本打不开**。html 是 PC 思维：双击文件、浏览器打开。读者早就不在 PC 上了。

一个额外的观察：在聊天里，**一张图 = 一个气泡，一个 PDF = 一个气泡，三千字纯文本 = 一整屏刷过去**。这就是「长文本不礼貌」的物理原因——它占别人的屏幕。

## 2. 墙内

### 2.1 微信：成年人的主场

微信是墙内的默认联系方式，但它有四个完全不同的「出口」，别混：

**聊天 / 群**：发图、发 PDF、发 txt 都能内联预览。发 md 会显示成一个灰色的未知文件图标。这是给朋友看稿子最直接的地方。

**朋友圈**：只能发图（最多 9 张）和短文字。长图在朋友圈的缩略图会被裁成方块，右下角标「长图」，点开才是完整的。所以长图别做成一整条几万像素的——切成每张两三屏高的几段，缩略图里还能看出是字。

**公众号**：这是墙内「认真发表」的地方——排版好、字号可调、读者有阅读体验，文章可以转发、收藏。代价是门槛：要注册（实名、手机号）、每篇要过审、个人号每天推送次数有限（⚠ 一天一次）。作者在网页编辑器里粘纯文本进去排版。**对我们来说：出一份干净的纯文本就够了。**

**微信读书**：这是很多人不知道的一条路。微信读书是腾讯的阅读器 app，可以「传书」——把 txt / epub / pdf 文件发到微信聊天里，点开选「用微信读书打开」，或者在电脑上打开微信读书网页版上传。传进去的书和买的书一样翻页、调字号、进度多设备同步。**这是 epub 在墙内唯一像书的落点**；不过它也吃 txt 和 PDF，所以不一定非 epub 不可。

### 2.2 QQ：为什么是年轻人的

微信在年轻人眼里是「爸妈和老师用的」。00后、10后的社交在 QQ：QQ 群、群文件、QQ 空间的说说。

对分享稿子来说，QQ 和微信几乎一样（图、PDF、txt 内联预览），多一个「群文件」——一个群共享的文件夹，丢进去所有人都能翻。**学生在 QQ 群里传小说 txt 是十几年的老传统**，传到手机后再用 QQ 阅读或微信读书打开。

### 2.3 微博 / 小红书 / B 站：长图文化的老家

**微博**：「长微博」这个词就是从长图来的——微博早年 140 字限制，大家就把长文截成一张长图发。现在有「头条文章」可以发长文，但长图习惯留下来了。一条微博最多 9 张图（⚠ 会员 18 张）。

**小红书**：图文笔记，一篇最多 18 张图，信息流里图会被裁成 3:4 的竖框。用户以年轻女性为主。「文字图」（把一段字排成一张图）在小红书上非常常见，是那里的原生形式。**给小红书的长图要按 3:4 切**，一张一屏。

**B 站**：视频为主，但有「专栏」（富文本长文）和「动态」（9 图）。00后浓度高。

### 2.4 认真发表：连载平台和同人圈

**LOFTER**（网易，2011 年起）：**墙内的同人圈中心**。像 Tumblr（它就是学 Tumblr 的）：发文配 tag，读者顺着 tag 找。2020 年 AO3 被墙之后，LOFTER 成了同人作者的默认落点（虽然它自己也经历过几次出走潮 ⚠）。

**晋江文学城**：女频（言情、耽美）连载站，学生读者多，审核严（涉政涉黄词自动屏蔽）。**起点中文网**：男频（玄幻、都市），阅文集团的。**番茄小说**（字节）、**七猫**（百度系）：免费 + 广告模式，2020 年代读者量冲到第一梯队（⚠），下沉市场。**QQ 阅读**：阅文的阅读器，也能导入本地 txt。

这几家的共同点：作者在后台一章一章粘纯文本；要收入得签约，签约通常要独家。**朋友之间分享稿子不走这里**——这些是职业化的地方。

**知乎盐选、豆瓣阅读**：成年人、文艺向的短篇市场，也是平台编辑器粘文本。

### 2.5 网盘：别走

百度网盘（限速）、夸克网盘（阿里系，2023 年后成了学生找「资源」的首选 ⚠）、阿里云盘。传文件发链接，对方要装 app、要登录、可能还要会员才不限速。**朋友之间分享一篇稿子不值得走这一步。**

### 2.6 电脑在墙内的位置

00后的电脑用途 = 打游戏、上网课（2020–2022 年疫情让很多家庭第一次买了电脑和 iPad）、做创作。**读小说几乎全在手机**。所以 html、epub 这类「在电脑上双击就能开」的格式，开的是作者自己的电脑，不是读者的。

## 3. 西方

### 3.1 聊天：Discord 和 iMessage

**Discord**：本来是游戏语音软件，现在是西方所有「圈子」（同人、游戏、独立创作、开源）的公共客厅。一个「服务器」里分频道，像 QQ 群但结构更深。PC 和手机双栖——这是它和微信 / QQ 最大的区别，很多人在电脑上开着它。

发文件：图直接显示；小的 `.txt` 有内联预览（大的要下载）；PDF 有预览（⚠ 2023 年起）；epub、html 不认。单条消息文本上限 2000 字符（Nitro 会员 4000 ⚠），所以长文本在 Discord 里必须切段，非常不礼貌。

**iMessage**（iPhone 之间）、**WhatsApp**、**Telegram**：私聊。PDF、图、txt 都是点一下 Quick Look。**epub 在 iPhone 上会直接进「图书」app**——给 iPhone 朋友发 epub 是个小惊喜，但 Android 朋友要先装阅读器。

### 3.2 Google Docs：美国中学生的母语格式

美国公立学校普遍给学生发 Chromebook（谷歌的廉价笔记本），一切作业在 Google Docs 里写、用链接交。这一代人**分享文字的本能是「发个 Docs 链接」**，不是发文件。Docs 链接在手机上点开就是可读的（网页或 app）。对我们来说：出纯文本，粘进 Docs 就行。

### 3.3 社交：X、Instagram、Tumblr

**Twitter / X**：创作者主场，一条最多 4 张图，预览会裁切。西方有个和长图对应的文化叫「Notes app 截图」——想说的话超过字数限制，就在手机备忘录里打好、截图发出去。**这就是西方版的长图**，所以长图在这边也是被接受的形式，切成 ≤4 张。

**Instagram**：图片轮播，一条最多 10 张（⚠ 2024 年起 20 张），竖图 4:5 最合适。年轻人多。

**Tumblr**：西方同人圈的老家，富文本长文 + tag，2010 年代最盛，现在小众但活着。

### 3.4 AO3（Archive of Our Own）

**是什么**：一个**非营利、志愿者运营、没有广告、没有推荐算法**的同人作品档案馆，2009 年由 OTW（Organization for Transformative Works，再创作组织）建立，2019 年拿过雨果奖。中文圈叫它「AO3」或「三次元」。**2020 年 2 月因肖战粉丝举报事件被墙**，这是墙内同人圈集体迁往 LOFTER 的直接原因。

**发什么**：以同人为主，但**原创也收**——把 fandom（作品分类）标成「Original Work」即可。作品叫 work，可以分 chapter 连载。

**怎么发**：网页编辑器，粘富文本或 HTML。没有官方 app，但网页对手机友好，读者习惯在手机浏览器上看。**注册要排「邀请队列」**（申请邀请，等几天收邮件 ⚠ 现仍如此）。

**tag 是它的文化核心**，发文时要填：分级（G / T / M / E）、Archive Warnings（暴力描写 / 主要角色死亡 / 非自愿 / 未成年，或「作者选择不标」）、关系类型（F/M、M/M、Gen……）、CP、角色、自由 tag。读者靠 tag 精确筛选和避雷。志愿者「tag wranglers」会把同义 tag 归并。没有 tag 意识的作品在 AO3 上没人看得到。

**读者互动**：kudos（点赞）、comment、bookmark、hits。

**对我们最有参考价值的**：AO3 给每篇作品提供**下载**——EPUB、MOBI、AZW3、PDF、HTML 五种格式。这就是「一篇文出门该有哪几种形态」的现成答案。

### 3.5 Royal Road

**是什么**：西方最大的**原创 web serial（网络连载）**站。名字来自韩国小说《月光雕刻师》里的游戏，早年是韩日轻小说英译的聚集地，现在是英文原创。类型极其集中：**LitRPG**（游戏系统流）、**progression fantasy**（升级流）、异世界转生——基本就是英文版的起点男频。

**怎么运作**：作品 → 章节，作者在富文本编辑器里发（可以直接粘 docx）。读者打分（0.5–5 星）、评论、追更。首页有 Rising Stars 榜、Trending 榜，**更新频率决定一切**——一周 1–3 章是常态，断更掉榜。很多作者用 Patreon 收费：付费读者提前看几章。

**读者在哪**：网页（手机友好）和 app（⚠）。

**对我们的含义**：粘纯文本进去就行。它是「连载」模式，不是「一本书」模式。

### 3.6 其它

- **Wattpad**：手机优先、青少年（尤其女生）、言情向。作者在 app 里写。曾是青少年写读小说的第一站，2020 年代热度让位给 TikTok 和 AO3。
- **Scribble Hub**：Royal Road 的宽松版（允许更多成人内容），同一批读者。
- **Substack**：邮件订阅平台，有人拿它连载小说，读者收邮件。
- **Kindle / KDP**：亚马逊自出版，上传 epub 卖书。**Patreon / Ko-fi**：读者赞助。
- **BookTok**：TikTok 上的读书圈，2020 年代决定了很多书的销量——但它推的是出版了的书。

### 3.7 电脑在西方的位置

Discord 让电脑还在社交里活着；青少年有游戏电脑或学校的 Chromebook。但读长文的人也在手机上。

## 4. 日本

### 4.1 LINE 和 X

**LINE** 是日本的微信位——私聊、群、家庭、学校都在这。发图、PDF 内联预览。**Twitter / X** 是日本创作者（「創作クラスタ」）的主场，比在美国还重要：画师、写手在 X 上发预览、挂 pixiv 链接。

### 4.2 pixiv 小説

pixiv 大家知道是画站，但它从 2010 年（⚠）起就有**「小説」**这个和插画并列的内容类型，是日本二次创作小说最大的落点，原创也很多。pixiv 在墙内不稳定（⚠ 2017–2018 年起时通时不通），但中文同人圈用得很多。

**格式是它的特色**：纯文本 + pixiv 自己的一套标记——
- `[newpage]` 分页（读者一页一页翻）
- `[chapter:见出し]` 章节标题
- `[[rb:漢字 > かんじ]]` 注音（ruby，日文小说的刚需）
- `[pixivimage:插画ID]` 把 pixiv 上的一张插画嵌进文里
- `[jump:页码]` 页内跳转

作品可以组成「シリーズ」（系列）连载；可以传封面（表紙）或用它的模板生成；R-18 要标。**读者在 app 里可以切成縦書き（竖排）**——这对日本读者不是可选项，是习惯。

### 4.3 BOOTH

pixiv 开的店（2013 年起）。**可以卖数字商品也可以寄实体**：上传 PDF / epub / zip 就能卖，价格可以设 **0 円**（这就是「无料配布」——免费发放，同人圈常见）；实体本可以用它的仓库服务代发（「あんしんBOOTHパック」匿名配送 ⚠）。买家用 pixiv 账号登录，信用卡 / PayPal / 便利店付款；海外买数字商品没障碍。

**你问「BOOTH 可以发小说对吧」——可以，而且「PDF 同人誌」就是「装订好的小书」在日本的原生形态**：同人作者把小说排成 A5 / 文库本尺寸的 PDF，在 BOOTH 上 0 円或几百円发放，读者下载后在手机或平板上翻。

### 4.4 なろう、カクヨム 和「縦書き」

**小説家になろう**（2004 年起）：日本最大的 web 小说站，「なろう系」（异世界转生）这个词就是从它来的。免费、无广告、排行榜文化。作者粘纯文本，注音写成 `|漢字《かんじ》`。**站方给每篇作品提供「縦書きPDF」下载**——把横排的网页文自动排成竖排 PDF 给读者——这个功能可以直接当我们 PDF 竖排档的参照。

**カクヨム**（KADOKAWA + はてな，2016 年起）：出版社办的，比赛通道多（拿奖 = 出书）。**アルファポリス**、**エブリスタ**（手机优先）：同类。

**pixivFANBOX**：pixiv 的 Patreon，赞助制连载。

**縦書き是硬偏好**：日本读者看横排小说会有「外国感」，正式的书、文库本全是竖排。给日本读者的 PDF 要竖排；纯文本粘进平台由平台竖排。

### 4.5 设备

日本年轻人 iPhone 占比很高（⚠ 过半），电脑普及率在发达国家里偏低——比墙内更「手机唯一」。

## 5. 00后 / 10后：screen time 墙里面是什么样

先校准年龄：2026 年，**00后 16–26 岁，大部分已经成年，出了墙**；**10后 6–16 岁，全在墙里**。下面说的「墙」主要是 10后和 00后尾巴的现实。

### 5.1 墙内

**门有几道**（规则是记忆，⚠ 核）：
- 2021 年教育部规定手机「原则上不得带入校园」，带了要上交。
- 2021 年 8 月游戏限时：未成年人只能在周五六日和节假日 20:00–21:00 玩网游，实名认证。
- 「青少年模式」→ 2024 年起升级为「未成年人模式」（《未成年人网络保护条例》2024 年 1 月 1 日生效）：短视频类每天限时、内容池受限、夜间禁用；家长还会叠 iOS「屏幕使用时间」或手机厂商的家长控制。

**设备是什么**：
- **电话手表**（小天才为首）：10后的第一台联网设备，也是他们的社交网络（「碰一碰加好友」）。封闭商店，装不了普通 app——你发的东西他们在手表上看不到。
- **学习机**（步步高、学而思、科大讯飞、小度）：锁商店的平板，家长买来「只能学习」。
- **父母淘汰的旧手机**：最常见的真实入口，往往没有 SIM 卡只连 WiFi。
- **iPad**：2020–2022 年网课时期大量进入家庭。
- **电脑**：在家里是「学习用」，装什么家长管。

**平台在哪**：**QQ 是他们的**（群、群文件、空间），微信是家长和老师的。B 站、小红书、抖音（未成年人模式下阅读类内容会被卡）。同人在 LOFTER。免费小说在番茄 / 七猫；女生看晋江。**在 QQ 群里传 txt、用微信读书或 QQ 阅读打开**——这条老路在他们这一代还活着。

**含义**：给 10后的东西必须**不装 app、不登录、不走网盘**，而且要能在 QQ 里点开。排序是**长图 > txt > PDF**。

### 5.2 西方

- 门：COPPA（13 岁以下不能注册大部分服务）；学校 Chromebook 锁应用但不锁浏览器和 Docs；家长用 iOS Screen Time / Google Family Link。
- 设备：学校发的 Chromebook 是主力；手机是 iPhone 为主（美国青少年 iPhone 占比极高 ⚠）。
- 平台：Discord 名义上 13+，实际是初中生主场；Snapchat、Instagram、TikTok；写读同人在 Wattpad / AO3 / Tumblr；BookTok 决定他们读什么书。
- 含义：Docs 链接和 Discord 里的图、PDF。

### 5.3 日本

LINE 是学生的；X 上中学生创作者不少；pixiv 有年龄门（R-18 要成年）。

## 6. 手机 vs 电脑，一句话

**读者在手机上，作者在电脑上。** 出门的格式按读者筛（手机、不装 app、不登录、内联能开），只剩图、PDF、纯文本。html 是给作者自己电脑的，不做。

## 8. 实体与非 screen-time 信道（user 2026-09-30「实体非screen time的信道也多想想」「没网的小孩和我可能也对实体感兴趣」）

前面七节全是「屏幕里」的路。但有两群人不在屏幕里：**被 screen time 管着的小孩**，和**想要一本能拿在手里的书的你自己**。这一节想的是纸、墨水屏、和不经互联网的传法。

### 8.1 打印店：三个地方各有一套

**墙内**：校门口的打印店是学生最熟的实体信道——U 盘或微信发个 PDF 过去，A4 一张几毛钱，**骑马钉、胶装几块钱**，十分钟拿走。家用打印机在墙内不普及，打印店就是家用打印机。

**美国**：家用打印机普及率高；公共图书馆有便宜甚至免费的打印额度；学校有打印机；FedEx Office / Staples 做装订。

**日本**：**便利店打印**（コンビニプリント）是一整个文化——在 7-Eleven 的 netprint 或 Lawson / FamilyMart 的ネットワークプリント网站上传 PDF，拿到一个番号，走到任何一家便利店的多功能复合机上输入番号就打出来，A4 / B5 / A3 都行，还能打**照片尺寸（L 判）**。同人圈用它发「無料配布」和「コピー本」（复印本）；正式的同人誌走印刷所（同人誌印刷所是一个成熟行业，最小起印几十本）。

**对我们的含义**：打印店要的是**一份按纸张尺寸排好的 PDF**（A4 / B5 / Letter），不是手机比例的。所以 PDF 至少两档：手机屏一档、纸一档。

### 8.2 三种小书，前两种不需要任何工具

**一纸八页折本**（one-sheet zine / 折り本）：一张 A4 或 Letter，横向对折两次、中间剪一刀、翻折起来 = **一本 8 页的口袋书**，不用钉不用胶，小孩自己能折。西方 zine 圈和日本折り本圈都用它。一张纸 8 页、每页 A7 大小，能放一首诗、一个片段、一个短短篇。**这是「没网的小孩」最容易拿到手的形态**：打印店打一张、或者家里打一张，折一下就完了。

**骑马钉小册子**：A4 对折成 A5，中缝钉两针。打印店的基本服务。16–48 页最合适（太厚钉不住）。中篇、几章合集。

**胶装**：打印店论文那一套，几十到几百页。整本书。

三种小书对 PDF 的共同要求是**拼版**（imposition）——纸的正反面、页的顺序要按折法排（骑马钉的第一张纸正面是「末页 | 首页」）。**拼版是 PDF 导出的一个模式，不是另一个产品**——这就是 PDF 和实体迷你书对齐的接口。

### 8.3 电子墨水：家长眼里的「不算屏幕」

很多家长把 Kindle 这类墨水屏阅读器排除在 screen time 之外。传书的路：

- **Kindle**：「Send to Kindle」——每台 Kindle 有一个专属邮箱，把 PDF / epub / docx 发到那个邮箱就出现在设备上；也有 app 和网页上传。
- **Kobo**、**文石 BOOX**（墙内主流安卓墨水屏）、**汉王**、**微信读书墨水屏版**：USB 拷或各自的传书。
- 墨水屏对**PDF 页面比例敏感**：6–7 寸屏看 A4 PDF 字太小，手机比例那档反而合适。

### 8.4 不经互联网的近场传输

「没网」不等于「传不了」：

- **AirDrop / 隔空投送**（iPhone ↔ iPad ↔ Mac）、Android 的 **Quick Share**、华为分享、小米互传——都是本地无线、不要账号、不要互联网。只有 WiFi 的旧手机和 iPad 也能收。
- 对我们最重要的一点：**PWA 里的「分享」按钮可以直接调系统分享面板**（Web Share API `navigator.share({ files })`，iOS 15+ 支持带文件 ⚠），面板里 AirDrop、微信、QQ、LINE、Discord 全都在——**不用「下载再去相册找」**。这一下决定了导出的手感。
- **U 盘 / SD 卡**：学习机的文件管理器一般认 PDF（⚠ 各家不同）——PDF 可能是唯一能进学习机的形态。

### 8.5 人对人的实体场合

- **同人展**：墙内的 CP（ComicUp）和各地 only 展，日本的 Comiket / COMITIA（原创专场），美国动漫 con 的 artist alley——**实体本是那里的货币**，无料配布的折本是入场券。
- **文学社、校刊、班级传阅**：学生时代的发表渠道，打印店骑马钉就是它的载体。
- **独立书店 zine 寄售、图书馆 zine 库**（美国一些公共图书馆有 zine collection）。
- **邮寄**：信里夹一本折本；**明信片**印一段；**书签**印一句——这些是「片段」的实体形态，和长图对应。

### 8.6 声音（只记不提）

睡前、车上、走路，是「非屏幕」的阅读时间。本机 TTS 出一段 mp3 是可能的形态。记一笔：家规 #8 管的是**用户的声音不出设备**、sunset 的是**识别**，合成朗读不在那条红线里；但这是新一类功能，不在这轮范围。

## 7. 对小黑屋导出的含义（摘要，决定在提案 doc）

| 形态 | 去哪 | 适合多长 |
|---|---|---|
| **长图** | 微信群 / 朋友圈 / QQ / 微博 / 小红书 / X / Discord / LINE | 短篇、单章、片段。一张舒服的长图 ≈ 3 屏 ≈ 3000 字（1080 宽、32px 字、30 字一行、一屏约 35 行）；单张硬上限来自 iOS 老 Safari 的画布面积（约 1080×15000 ≈ 8–9 千字 ⚠）。整本别做长图，切太多张没人翻 |
| **PDF** | 微信 / QQ / iMessage / Discord / LINE 私聊和群；BOOTH；将来的实体迷你书 | 整本、中长篇。页面按手机比例，大字，章起新页 |
| **纯文本（markdown 树）** | 公众号 / 晋江 / LOFTER / AO3 / Royal Road / pixiv / なろう / Google Docs 的编辑器；喂 AI；备份 | 任意长。社交上直接贴不礼貌，它是原料不是成品 |
| epub | 只有 iPhone Books / 微信读书 / AO3 读者习惯 | 你的判断：没消费者，不做 |
| html | 无 | 不做 |
