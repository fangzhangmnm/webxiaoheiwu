## 1. 要解决什么

在 PC 上，user 想开一个很小的窗口写字，压在别的窗口上面，比如等 Claude Code 的时候写几句。现在只能把标签拖出来，但拖出来的窗口和原窗口一样大，每次都要手动拉小，很难受。网页改不了被拖出来的窗口大小（浏览器只允许脚本改自己用 `window.open` 开的弹窗），所以要换个动作：在 WXHW 里按一下，直接弹出一个四行稿纸大小（三行字 + 一行空的）、置顶、没有地址栏的小窗。

## 3. 小窗的 UI

```
┌──────────────────────────────────────────┐ ← 浏览器自己画的细标题栏（站点 · 回到标签页 · ×）
│ 雨停了以后，她才发现伞忘在了车上。     🔒 │
│ 「明天再去拿吧。」他说。               ☁  │
│ 她点点头，又摇了摇头。▍                   │
└──────────────────────────────────────────┘
```

用内置输入法打字时：

```
┌──────────────────────────────────────────┐
│ 1自然 2字 3子然 4自燃 …            ziran  │ ← 候选条临时占掉最上面那一行
│ 「明天再去拿吧。」他说。               ☁  │
│ 她点点头，又摇了摇头。▍                   │
└──────────────────────────────────────────┘
```

- **非常 borderless、精简**（user 10-24：「小窗就是非常borderless精简的」）。标准照 KudsRocket 的小窗：它 v0.2.8（10-24）刚按 user 截图改过，user 原话是「逃生口的三个键在小窗或者全屏模式把所有东西都遮住了」「鼠标一移上去就立马高亮然后挡住了一堆屏幕空间」。所以小窗里任何东西都不许盖住内容，悬停时不许变样。
- **只有稿纸**：稿纸贴满整个小窗，没有纸边、阴影、页边距，背景就是纸色；没有页头、章节导航、侧栏、菜单。横线照画，用和大窗同一套稿纸几何（`src/ui/paper.ts`）。
- **小窗里不放按钮**：收回靠 Alt+P、小窗的 ×、浏览器标题栏的「回到标签页」。KudsRocket 小窗里有「快照 · 软键」两个逃生键，那是游戏才需要的，WXHW 不需要。
- **窗口高度收成整数行**：浏览器照记住的大小开、露出半行时，在小窗里下一次按键松开（有用户手势）时用 `resizeBy` 收到整行。做法照 KudsRocket 的「收窗」（`src/app/pip.ts`：小窗的 `outerWidth` 读出来是 0，只能按增量改）。
- **正在写的那一行贴底**：光标所在行始终是第三行，下面空一行，旧的行往上走（和打字机模式同一个排法：光标跟随本来就在光标行下面留一行）。几行亮度一样。
- **行宽**：稿纸本来就会按宽度自动排字（窗口窄了就每行少排几个字，字号不变）。小窗第一次的宽度按这本书的行宽算，比如 20 字乘以字号再加左右留白。高度 = 四行 + 上下留白。用户拖过以后，下次照拖过的大小开（Chromium 会记住，要实测）。
- **状态必须看得见**：右边距放两枚小图标，一个表示加密状态，一个表示云端状态（user 09-30：「加密状态和云状态必须可见！」）。要小、要淡，坐在右边距里，不压字，悬停不变样。只显示，不能点；要处理就收回大窗。
- **内置输入法的候选条**：拼字时临时占掉最上面那一行，打完就还回来。正在写的那一行始终露着。用系统输入法时，候选窗是 Windows 自己画的，不归 app 管。
- **需要弹面板的事件**（冲突、密码、出错）：先把稿纸收回大窗，再弹面板。小窗里不放任何面板。
- **2 分钟闲置锁屏**：先收回，再锁。不让加密稿的明文留在置顶窗里。
- **父标签**：稿纸原来的位置放一块占位，写着「正在小窗里写」和一个「收回」钮。
- **收回的方法**：Alt+P（两边窗口都认）、小窗的 ×、浏览器标题栏的「回到标签页」、父标签占位里的「收回」。

## 4. 实现要点（给做的人）

- **搬，不抄**：把稿纸容器（稿纸 + 候选条 + 状态图标）整块搬进小窗的文档，原来的代码照样驱动这些元素，不另写一份。KudsRocket 的 `src/app/pip.ts` 是先例：抄样式表、小窗 `pagehide` 时搬回来、原位放占位。
- **一个接缝：「稿纸现在在哪个窗口」**。现在挂在整页上的监听大约有二十几处（10-24 数的：`app.ts` 16、`input/pipeline.ts` 9、`idle-gate.ts` 4、`input/dock.ts` 3，其他零星）。它们只认主窗口，用户在小窗里打字它们听不见。下面几类要改成挂在接缝上：
  - 输入法键盘道：`pipeline.ts` 的 keydown / keyup / beforeinput / compositionend。
  - 闲置计时：`idle-gate.ts` 的 keydown / pointerdown。不改的话，人在小窗里一直打字，两分钟后照样被锁。
  - 快捷键：`app.ts` 的 keydown（Ctrl+S、按住说话键、Alt+P 本身）。
  - 尺寸：resize 触发的 `paper.refresh()` / `followCaret()`。
  - 焦点恢复：window 的 focus。
  - 跟稿纸无关的（online / offline、error、CSP 报告、`pagehide` 落盘）留在主窗口不动。代码都在父页面里跑，`pagehide` 落盘照样生效。
- **守卫测试**：稿纸、输入法、闲置相关的文件里，禁止直接写 `window.addEventListener` / `document.addEventListener`，必须走接缝。以后加功能也漏不掉。
- **CSP**：`style-src` 里有 `'unsafe-inline'`，照 KudsRocket 的做法把样式抄成 `<style>` 可行；字体走 `font-src 'self' data: blob:`，照常能用。
- ⚠ **跨 realm**：小窗文档里新建的元素不是主窗口 `HTMLElement` 的实例，事件处理里的 `instanceof` 判断要小心。搬过去的元素不受影响。
- **要实测**：① Edge 的睡眠标签页会不会把在后台的父标签睡掉，连带小窗一起关（正在放声音的标签不会被睡，WXHW 不出声）；② 浏览器会不会记住小窗大小；③ 系统输入法的候选窗在小窗里出现在哪。

## 5. user 10-24 的答复（原「待 user」）

- 几行：「一行空的，三行字，我看了之后调」→ 四行高（三行字 + 一行空的，和打字机模式同一个排法）。做出来以后 user 看了再调。
- 字数和标题：「不放，都不放，盲人。说出去的话泼出去的水」。
- `pip.ts` 抄还是抽库：user「感觉共用的东西应该不多？如果我错了可以pushback」→ Claude 同意不抽库：两家真能共用的只有五六十行（检测 API、开窗、抄样式、抄图标 sprite、搬过去搬回来）；收窗的判据不同（KudsRocket 按画面比例、WXHW 收到整行）；WXHW 最费事的接缝改造本来就不共用。照形状抄一份，第三家要用时再抽。
- 小窗里能不能翻页（user：「不过打字机小窗能做页面导航吗？」）：能。WXHW 已有 Alt+↑ / Alt+↓（上一页 / 下一页，全树前序）和 Alt+←（回退），挂在 `app.ts` 的 document keydown 上；这条监听按 §4 改走接缝之后，在小窗里照样能按。小窗里不加按钮。

## 6. 做的时候和稿子不一样 / 稿子没写到的（v2.3.60）

- **名字**：user 2026-10-25「小窗是迷你模式对，不过就叫小窗也行」→ 照旧叫「小窗」。

- **入口**：除了 Alt+P，侧栏顶行加了「小窗」图标（stopgap「窗」字）。`picture-in-picture` 在本 app 已经是参考窗，所以另登记了 `mini-window`。浏览器没有这个 API 时入口**不露**（稿子原写「照 KudsRocket 写明不支持的原因」；改成不露，免得 iPad / Quest 上多一个点不了的图标），Alt+P 只在状态行说一句。
- **候选条在小窗顶上**（和 §3 原稿一致）：贴底会压到正在写的第三行。
- **点名藏，不能写 `.page > :not(.page-body)`**：paper.ts 的量尺探针和孪生框也是 `.page` 的直接子元素，藏了正文高度会量成一行。toast、锁卡也在 `.page` 里，一起藏。
- **`html` 要 `overflow: hidden`**：不然 `body` 的 overflow 被提到视口上，`body.scrollTop` 没用，光标钉不住。
- **占位多一句**「关掉这个标签页，小窗也会一起关」（照 KudsRocket）。
- **按住说话**：v2.3.60 没挂进小窗，v2.3.61 补上（user「能用」）；正在听时小窗右上角多一枚强调色话筒。toast 在小窗里照旧藏着。
- **没做**：拖出半行后「收成整行」只有单测，探针里没法模拟人拖窗口。
