## 1. 是什么

整页（NVL）和对话框（ADV）是同一条段落流的两种看法。整页 = 现在的稿纸，字铺满一张纸；对话框 = 屏幕底下一个几行高的框，框里只有**一段**（当前这一段），一次写一段，回车就发出去。对话、动作是一串短段；设定是一长段，读的时候按一下 › 就过去。切换只靠人（钮 / Alt+T / 台上右上角），app 不因为段长了替人切。

段 = 两个以上换行隔开的一截（单个换行留在段里）= 一个语义拍：拍里一句句对话往来用单换行隔开（user 2026-10-26：老稿里空一行分的就是「不同的语义拍。不是一个一个对话来往」）。这正好是 Ren'Py 的一句台词的单位：说话人、选项照 Ren'Py 的写法敲进那一段就行（文件里存什么形状见 §6）。

## 4. 实现

- **真相只有正文框**（`#editor`）。框（`#advInput`，`src/adv/box.ts`）是正文 `[start, start + shown.length)` 那一截的一扇窗：框里每改一次，`diffEdit` 算出改了哪一截，原样写回正文那个位置（`text-edit replaceRange`；正文框没焦点 → `setRangeText` + 补发 `input`），所以落盘 / 推云 / 字数 / 子节目录都照旧听正文的 `input`，对话框不另开任何持久化。
  - 写回前核对正文那一截还是框里上一版的字；对不上 = 正文被别处改过而框没跟上 → 不写、按正文的光标重取，宁丢框里这一下也不往错的位置写字（`console.warn` 留痕）。
  - 写回前过 `canEditNow()`（锁 / 只读 / 世界线守卫）；框的 `readOnly` 跟着正文框。输入管线的 `canEdit` 把框和正文框当同一把锁。
  - 段落模型是纯函数 `src/adv/paragraphs.ts`（`paragraphs` / `paraIndexAt` / `diffEdit`，`test/adv-paragraphs.test.mjs`）。分隔原样留着（三个换行就是三个），只负责「哪一截算一段」。
- **回车**：三条路（实体键盘、app 软键盘、系统键盘）最后都是框里多了一个换行 → 在框的 `input` 里认出「刚插了一个换行、前一下不是 Shift+Enter」→ 写回时换成两个换行、框换段。不拦三个入口。贴进来好几段 = 原样写回、框落在光标所在的那一段。
- **段首退格** = 删掉两段之间的分隔（回车的反操作）。实体键盘走框的 keydown；app 软键盘的退格在框最前面删不掉东西，`input/field.ts deleteBackward` 在框上发 `backspaceatstart`，框接住。输入法吃掉的键（组字中的回车 / 方向键）在捕获阶段就 `preventDefault`，框的 keydown 看 `defaultPrevented` 让路。
- **撤销只在这一段里**：换段 = 程序改框的值，浏览器清掉框的撤销栈。故意的——留着的话 Ctrl+Z 会把上一段的字「撤」进这一段的位置。框写回正文走 `setRangeText`，所以回到整页后正文的撤销栈也是空的。
- **别处改了正文**（语音落字、规整标点、检索跳转、换页、重载）→ 正文的 `input` / 宿主的 `sync()`（`renderTopbar` 里、`focusWriting` 里）让框按正文的光标重取。框的光标 / 选区在每次改字、抬键、点击、失焦时写回正文（`pushCaret`）；语音从正文的光标起录，起录前（话筒、按住说话）再写一次。
- **焦点**：对话框开着时正文框藏着（`visibility: hidden`，照样排版，`paper.ts` 的量尺 / 孪生框还要量），拿不到焦点。app.ts 里二十几处「回到正文」统一走 `focusWriting()`；「焦点在正在写的框上」统一走 `writingFocused()`（按住说话、退格钮、Quest 焦点找回）。`followCaret` 只认正文框，对话框模式下不动纸。
- **几何**（`styles.css` 末尾「对话框模式」一节）：框和纸同宽、同左右留白、同字体字号行高 → 每行几个字和整页一模一样。`--adv-h`（框总高 = 行数 × 行高 + 22）由 `app.ts syncAdvHeight` 写在 body 上，因为候选条 / toast 不在纸里、读不到纸上的行高。台 `--z-adv-stage: 4`（纸面浮件之下，参考窗 chrome − 2 自然在上）。框、台、角上的钮都住在 `.page` 里，开小窗时跟着纸一起搬。
- **格式**：editor-state **1.1.0 → 1.2.0**（加可选键 = minor）：`advLines`（读 1–12 的整数，界面只给 2–5）、`advBackdrop`（书里的页名，悬空的丢掉）。改名跟着改、删页跟着删（`graph.ts`，同 cover / exportCovers）。冻结样本 `test/fixtures/format/graph-2.1.0+editor-1.2.0`，钉表测试三处跟改。诚实账：prod（v2.3.39）没有格式纪律，它保存一次会丢掉这两个键。
- **图片 MIME 表**提成 `project/format.ts IMAGE_MIME`（书模式的页面图和对话框背景共用；参考窗另有一份带文字类型的，没动）。

## 8. 说话人识别 → 名字牌（v3.0.5）

- user 2026-10-26：「帮我想一下要不要自动识别说话人然后弹到（你知道galgame里面人名放哪里），也是文字照样打。自动识别。中文日文英文是不是不一样？一般剧本的格式是什么？这样我可以直接无痛写avg了。然后设置可以关」「嗯那么就有一个可展开的选项里面是可以勾选不同的说话人识别规则。然后还有一个整体的开关。默认关。然后还有就是如果是“hello"speaker"second"这种也不算」「然后中文最标准的 我说：“你好” 也记一下」「不过冒号引号也几乎是冒号的规则」「再剥掉末尾的“说/道/问/笑道”等字 用不到，不要谜语人。我们不需要非剧本稿能强行type cast」「我说：“你好” / 你好的引号也会有」。
- 名字牌 = galgame 名字栏的位置：框左上角、骑在上边线上；只看光标那一行；只显示；小窗里不放。正文一个字都不改。
- **段首的标记不进框**（v3.0.6，user「小月：  不进文本框啊」）：框露出的那一截从「段首 + 标记长度」起，标记（名字 + 冒号 / 】+ 后面的空白；日式只有名字，「」留在框里）只在名字牌上。打完「小月：」当场收进去；段首退格删掉的是冒号，名字回到框里；补回冒号又收进去。打字时只重看段首那一行（不扫全文）。单回车模式一段 = 一行，每句都收；空一行模式只收段首那一行，后面几行的标记照样露在框里、名字牌跟光标那一行认。小窗里不收（名字牌不放，标记得看得见）。纯 ASCII 的「名字」不归冒号规则（挡行首「12:30」、网址被收走）。
- 规则（纯函数 `src/adv/speaker.ts`，`test/adv-speaker.test.mjs`），只认**行首**的剧本类写法，名字原样、不做加工：
  | 规则 | 例子 | 备注 |
  |---|---|---|
  | 冒号 | 小月：明天再去拿吧。 | 全角 / 半角冒号；**冒号后面紧跟引号 = 小说写法（我说：“你好”），不认**——中文小说最标准的写法，记在这里，不硬套 |
  | 【名字】 | 【小月】明天再去拿吧。 | 汉化稿 / 文字游戏 |
  | 日式 | 小月「明日取りに行こう」 | 名字后面直接接「」『』 |
  | 英文 | TSUKI: Let's go. | 大写开头、≤ 3 个词 |
- 不认：引号中间夹说话人（“你好，”我说，“……” / "Hello," said Tsuki, "…" / "hello" speaker "second"）；名字超过 8 个字、名字里有空白或标点。首行缩进（含全角空格）不算。
- 设置「逐段」节（v3.0.5 起逐段的选项单独一节：框几行高 / 怎么分段 / 说话人识别）：总开关（synced prefs `advSpeaker`，**缺 = 关**）+ 可展开「识别规则」四个勾（`advSpeakerRules`，缺 = 全勾）。跟人走。
- 坑：纸搬进 / 搬出小窗那一瞬间两边都不在，框失焦也会报一行，名字牌按 id 现查会扑空 → 启动时记住引用（无头假小窗抓到）。
- 系统输入法 + 「打字时自动规整标点」会把「」换成设置里的弯引号：引号样式是弯引号的人写不出日式「名字「……」」，这是既有行为，没动。
- 文件形状：照现在这样存普通文本（段间空行，说话人 / 选项照 Ren'Py 写法自己敲），还是导出时 app 包成 Ren'Py 格式。Ren'Py 的缩进 / 引号规则还没查原文核。
