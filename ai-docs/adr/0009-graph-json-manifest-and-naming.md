# ADR-0009 graph.json 清单 schema 与节点命名规则
> created 20260909 · by Claude Fable 5.1 (claude-fable-5-1) · status: accepted（user 2026-09-09 grill）

## schema（version 1）

```json
{
  "format": "webxiaoheiwu",
  "version": 1,
  "wroteWith": "2.0.0",
  "nodes": {
    "夏音-第三次见面.txt": { "links": ["夏音.txt", "_废-第一版开场.txt"], "created": 1757400000000, "modified": 1757403600000 },
    "夏音.txt": { "links": [], "created": 1757300000000, "modified": 1757300000000 }
  }
}
```

## 决定
1. **身份 = 完整文件名 = 显示名**（`contents/` 下的 entry 名）。这是对 ORA 的一处明知偏离（ORA id 在清单、文件名派生）：graph.json 是可丢的 metadata，名字若住清单，丢清单等于丢名字。延续 ADR-0001 / ADR-0007「身份 = 路径名」。
2. **links 元素只允许名字**，且是**带扩展名的完整文件名**（user 选 A）。不允许分节行：user「`===` 是灵活语法导致的滥用，就和很多语言一样，我们的小黑屋本来就极简的」。分组靠命名前缀（`_废-…` 沉底）。
3. **占位符** = links 里出现、`contents/` 里没有的名字（Obsidian 未解析链接同款）。跳上去才生文件。零机制。
4. **边有向、零属性、零权重、零类型**。顺序 = 数组顺序（用户手排）。**反链不存**，是查询：在所有 links 里搜这个名字。
5. **撞名 = 完整文件名相等**，比较口径**大小写不敏感 + NFC**，扩展名不特殊：`夏音.txt` 与 `夏音.jpg` 是两个节点，合法共存。多个点不构成问题——身份不解析名字。扩展名只在渲染时解析（最后一个点之后），app 建的文件永远带 `.txt`；不认识的扩展名显示名字、不打开、不猜。
6. **打已有名字 = 链接不是新建**（wiki 规矩；撞名是强迫面对 pile of shame，user 同意）。不允许重名，不做 `.001`。
7. **改名** = 改 entry 名 + 重写所有引用它的 links 数组，一次整包写。
8. **created / modified 必有**（user「时间戳要」）：zip entry 时间戳钉 1980 后无处可放；`created` 事后补不回。只用于临时查询排序，**不做「最近编辑」面板**。这里没有 timelapse 那种「内耗即增重」，时间戳不长体重。
9. **`version` 太新 → 横幅 + 禁覆盖**（抄 WeebPaint `weebpaint:format` + `wrote-with`）。

## 系统对图零态度（journal 里 user 拍板，写进这里防漂移）
没有全图视图、没有全文件列表、没有孤儿面板、没有计数 / 进度 / 衰减 / 自动强弱。「有了就露馅」。检索至少两个字符、结果临时不留面板。工具唯一义务：不在用户没叫它的时候自己动。

## 否决
- stem 撞名（要定从第一个点还是最后一个点切，两种都有反例）。
- 不透明 id + `name` 属性（要自己维护唯一性；user 明确不许重名）。
- 边的强弱 / 档位 / 衰减（都是钮，都会变成形式判断）。
