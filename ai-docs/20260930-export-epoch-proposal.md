## 1. 现状（as-of v2.3.0）

- graph.json v2：`pages{<名>: {links, created, modified}}` + `tree` + 顶层 `readOnly`（ADR-0014）。树里**没有节点类型、没有 compile 标记**。
- 已有的「出门」动作：① 侧栏「导出」= 当前页全页进剪贴板（txt / 图片转 PNG）；② 树行菜单「导出这一支…」= 子树前序 DFS、只拼 txt 页、`\n\n` 连接 → 存进书库 / 下载 txt（`graph.ts exportSubtree`）。
- 字数：`doc-model.statsForText`（CJK 按字、拉丁按词），只在页脚显示当前页。
- 锁的可视化 = 顶栏一颗钮（`edit-enabled / edit-disabled`），书级布尔。
- 图片：`src/image/codec.ts` 是 app 唯一 canvas 点（解码读出一次）；编码 = vendored jpeg-js / UPNG。zip 引擎 `src/zip.ts`（按扩展名 STORE / DEFLATE）。
- 封面 = `Thumbnails/thumbnail.png` ≤256²；书库封面的**印书名排版** = `src/ui/book-cover.ts`（纯函数出 HTML）。
- 家族模型包机制 `20260903 PWA Models`（24 MiB 分片 + manifest sha256 + 用户可换镜像；下载那一下 = consent）——字体包可以直接走它。

## 2. 页的旗子（flag）

### 2.1 一条轴，不是四个布尔

user 列的词 flag / active / visible / hidden / public 我拆成：**active = 当前页（导航态，不是旗子）**；visible / hidden = 「在侧栏藏不藏」——这是第二条轴，我建议**不要**（ADR-0009「系统对图零态度」；workbench 里所有页都该看得见）；public = 出门。所以只剩**一条轴：这页出不出门**，四个值（闭集，typed enum）：

| 值 | 建议中文（词归 user 定） | 意思 | 出门（导出 / 长图 / 书）| 计入「已发布字数」 |
|---|---|---|---|---|
| `publish`（**缺省 = 字段不存在**） | 发布 | 成品 | ✓ | ✓ |
| `draft` | 草稿 | 还在写，将来会发布 | ✗ | ✗（可另报「草稿 M 字」） |
| `note` | 笔记（user 说的「私人参考」；「参考」一词已被参考窗占了，建议换字） | 设定 / 大纲 / 给自己看的 | ✗ | ✗ |
| `old` | 旧稿 | 被新版取代的版本 | ✗ | ✗ |

**缺省 = 发布**的理由：旗子只在例外时插（草稿 / 笔记 / 旧稿都是例外），老书零改动、不用每写完一章都去翻一下（[[feedback_app_must_not_discipline_user_20260929]]「故意加一个规则反而让用户开始 micro management」）。3 年前的废稿 = 一次「标为旧稿（连同 N 个子节）」。

> 注：09-10 user 拍过「zip 是 workbench 不是 museum，旧版本不进书」。现在「旧稿」当旗子进书是 user 自己用起来的需求（迭代 3 年前的废稿），不是我提的——但记一笔：`old` 这个值是否要，还是「笔记」就够（旧稿 = 笔记的一种），归 user。

### 2.2 数据

graph.json `pages[名].state?: "draft" | "note" | "old"`（缺 = publish；写出时 publish 不写字段）。version 仍 2（先例 = refPanel / references 都是加法不升号）。⚠ 代价：比 v2.3 老的 app 打开这本书再保存会**把旗子丢掉**（它只写 `{links, created, modified}`）。目前只有一台用户、prod 还是 0.2.21 开不了 v2 书，风险实际为零；若 user 要严格，升 version 3 让老 app 拒开（too-new 只读）——问题 §7-③。

### 2.3 hierarchy：三个候选模型 + 一张差异表

| | **C 每页各自一面旗（推荐）** | A 砍枝（父非发布 = 整支不出门） | B 继承可覆盖（CSS visibility 式） |
|---|---|---|---|
| 存什么 | 每页自己的值 | 每页自己的值 | 每页自己的值 |
| 读的时候算什么 | 不算，就是它自己 | 有效值 = 自己 ∧ 所有祖先 | 有效值 = 最近有旗子的祖先 |
| 父页是「第一幕」容器、正文是大纲（笔记），孩子是成品章 | ✓ 父标笔记，孩子照出 | ✗ 整幕消失，得把大纲挪进子页 | ✗ 孩子继承成笔记，得逐个覆盖 |
| 整支旧稿 | 「标为旧稿（连同 N 个子节）」一次批量写 | 只标根 | 只标根 |
| 旧稿支下新加一页 | **出生抄父的旗子**（新建时拷一次，不是运行时继承） | 自动被砍 | 自动继承 |
| 侧栏要画什么 | 只画自己的旗子 | 自己 + 「被祖先砍掉」的灰态 | 自己 + 继承来的虚态 |
| 与现有动词同形？ | 「连同 N 个子节」= 废弃的措辞；数据零 cleverness | 像 `display:none` | 像 `visibility` |

选 **C**：树只管归属与顺序（ADR-0014），旗子是页的属性，两层各管一件事；批量 = 动词不是机制；「新页出生抄父」解决旧稿支下加页的坑而不引入运行时继承。**导出 = 子树 DFS，跳过非发布页的正文但仍往下走**（容器页标笔记 ≠ 砍掉孩子）。

### 2.4 对现有动词的影响（C 模型）

| 动词 | 受旗子影响？ |
|---|---|
| 上一页 / 下一页 / 侧栏邻域 / 检索 / 参考窗链接卡 | 否（workbench 视角，所有页照走） |
| 导出这一支 / 长图 / PDF / EPUB / 剪贴板整支 | **只收 publish 页**（图片页同规则：图片页也能标草稿 / 笔记） |
| 页脚字数 | 否（仍是当前页自己的数） |
| **书的已发布字数**（新） | 只加 publish 页；显示位置 §7-④ |
| 废弃 / 挪到 / 移出树 / 彻底删除 / 改名 | 否；改名 / 废弃跟着页走（旗子在 pages 表里，键跟着改） |
| 新建兄弟 | 出生抄**当前页**的旗子 |
| 新建子节 / 图片进门 / 拖放粘贴 | 出生抄**父页**的旗子 |
| 「标为…」 | 顶栏「+」菜单 + 侧栏树行菜单 + 纸上印章点了 → pick sheet 四选一；有子节时多一行「连同 N 个子节」勾 |
| 锁（readOnly） | 正交：锁 = 不能改；旗 = 出不出门。锁着时旗子也不能改（走 `assertMutable`） |

### 2.5 可视化：印章，不是角标

「像锁一样：轻松看见、不干扰」→ **发布 = 什么都不画**（99% 的页零噪音）；非发布 = 纸的右上角（章节名行末）一枚小印章：哑朱色、细框、两字（草稿 / 笔记 / 旧稿），大小 ≈ 一个字高，点它 = 换旗；侧栏行名字后同款缩到 9px 的小章。稿纸 + 印章是这个 app 的气质（书库封面已经是「纸 + 装订线」）。**图标**：家族图标库有 `stamp`（橡皮图章）一枚泛用；印章里的字要烤（`tools/bake-stopgap-glyphs.py` 中文烤轮廓）或走 PENDING 让我画 3 枚 `stamp-draft / stamp-note / stamp-old`——**新增图标需求 3 枚，登记 `20260708 SVG Icons/TODO.md`**（动手时办，先报备）。

## 3. 生态科普（三张表 + 一代人）

读法：**「读者怎么开」这一列决定我们出什么格式**。凡是「内联预览」的格式不用装 app、不用登录，是朋友真会点开的那种。

### 3.1 墙内

| 渠道 | 谁在用 | 作者怎么发 | 读者怎么开（手机） | 对我们的含义 |
|---|---|---|---|---|

### 3.4 00后 / 10后：screen time 墙里的现实（2026 年：00后 16–26 岁，多数已成年；10后 6–16 岁，全在墙里）

**墙内**（规则记忆，⚠ 做产品决策前核）：
- 门：2021 教育部「手机原则上不得带入校园」；2021-08 未成年人游戏限时（周五六日与节假日 20–21 点）+ 实名防沉迷；青少年模式 → 2024 起「未成年人模式」（《未成年人网络保护条例》2024-01-01 生效）：短视频类每日限时、内容池、夜间禁用；家长用 iOS 屏幕使用时间 / 手机厂商家长控制。
- 设备：**电话手表**（小天才为首，10后的社交网络，封闭商店，不能装普通 app）；**学习机**（步步高 / 学而思 / 讯飞 / 小度，锁商店）；父母淘汰的手机；iPad（网课遗产 2020–2022 大量进家庭）；PC 在家里是「学习用」。
- 平台：**QQ 是他们的，微信是家长的**（QQ 群、群文件、QQ 空间说说）；B 站、小红书、抖音（未成年人模式下阅读类被卡）；LOFTER（同人）；番茄 / 七猫（免费）；晋江（女频，学生读者多）；**微信读书 / QQ 阅读**导入 txt 的文化——学生在 QQ 群里传 txt 是老传统。
- 含义：**给 10后的东西必须不装 app、不登录、不走网盘**——**长图 > txt > PDF**，且能在 QQ 里点开。

**西方**：13 岁以下 COPPA 门；学校 Chromebook + Google Docs；Discord 名义 13+ 但实际是初中生主场；Wattpad / AO3 / Tumblr 是青少年写读同人的地方；TikTok「BookTok」决定书的销量；Notes 截图 = 长图文化。

**日本**：LINE 是学生的；Twitter/X 中学生创作者多；pixiv 有年龄门。

### 3.5 手机 vs 电脑：一句话

**读者在手机，作者在电脑**。出门格式按「手机、不装 app、不登录、内联能开」筛，只剩三样：**长图（图）、PDF、纯文本**；「像书」的加一样 **EPUB**（iPhone Books / 微信读书 / AO3 读者习惯）。**单文件 HTML** 是 PC 专属，微信拦、Discord 不认，排最后甚至不做。

## 4. 交付物闭集（差异表）

## 5. 工程

### 5.1 一个排版深模块，两个后端
`src/typeset/`（纯函数，零 DOM）：输入 = 页序列（标题 / 段落 / 图片）+ 字体度量 + 页面几何 → 输出 = 行与页（每行的字与 x 位置）。CJK 逐字断行 + 避头尾（行首不许 、。」』）+ 拉丁按词；段首空两格；标题另起。后端：**PNG**（把行画成像素）与 **PDF**（把行写成 `Tj` 算子）。EPUB 不经它。

### 5.2 字体与 canvas（这是唯一碰家规的决策点）
- **PDF 必须嵌字体子集**（否则读者设备没字体就方块）。方案 = vendor `pdf-lib` + `@pdf-lib/fontkit`（MIT，子集化现成，「避免重复造轮子」）；或自写最小 PDF writer + TTF glyf 子集器（几百行，可信深模块，但要造）。推荐 vendor。
- **字体本体走模型包机制**（`pwa-models` 新一类 pack：24 MiB 分片、sha256、用户可换镜像、下载 = consent）。候选（全部 OFL 1.1，可再分发、可嵌入文档，署名进设置页）：霞鹜文楷 LXGW WenKai（TTF，⚠ ≈18 MB，手写感与稿纸气质合）/ 思源宋体 Source Han Serif SC（OTF-CFF，⚠ ≈23 MB，子集化比 TTF 难）/ Noto Sans SC 可变（⚠ ≈10 MB）。日文读者要 JP 字形（思源有 SC / JP 两套），后话。
- **长图光栅化**：三条路——(a) canvas `fillText` + 系统字体（零体重，但 iPad / Win Mini / Quest 出来的图不一样）；(b) canvas `fillText` + 用 `FontFace` 装进字体包（设备无关，仍是 canvas，住 `codec.ts` 这个唯一 canvas 点，全 app 仍是 1 个 canvas）；(c) 自写轮廓光栅器（fontkit 给轮廓 → 自己填，零 canvas；WeebPaint 文本工具的正统路，但是个兔子洞）。**推荐 (b)**；(a) 若作为第一版兜底，退场条件 = 字体包落地那一版切到 (b)。家规「字节进出不走 canvas」在这里的读法归 user：§7-⑥。

### 5.3 EPUB 便宜
`mimetype` 首 entry STORE（`zip.ts` 加一个「首 entry 强制 level 0」参数）+ `META-INF/container.xml` + `OEBPS/content.opf` + `nav.xhtml` + 每章一个 XHTML + 封面图（`Thumbnails/thumbnail.png` 只有 256²，太小——封面来源 §7-⑤）。EPUB 3，`writing-mode: vertical-rl` 可选。

### 5.4 封面来源
缩略图 256² 不够印。选项：① 导出 sheet 里选一张图片页当封面（默认 = 子树里第一张图片页 / 无）；② 没图就用 `book-cover.ts` 的字封面（长图 / PDF 都能直接画，EPUB 用 SVG 封面）。不在 graph.json 加 cover 字段（ADR-0012「不要帮用户发明字段」）。

### 5.5 方言（只在 user 真去发时做）
pixiv `[newpage]` / `[chapter:]` / `[[rb:]]`；なろう `|漢字《かんじ》`；公众号无方言。做成 txt 导出的一个「格式」下拉，不是新交付物。

### 10.2 bookmaker（`OneDrive/Lab/20260731 bookmaker/`，LaTeX，user 说可以 sunset；内容 = 《七年级一班的夏音同学》）
- **引擎原则和我们一样**：「整个版面只由四个数决定」——`size` 字号、`chars` 每行几个汉字（版心宽 = chars × size）、`lines` 每页几行（版心高 = (lines−1) × 行距 + size）、`spread`（行距 = size × 1.2 × spread）。开本尺寸另给。
- **micro 开本（现役）**：内页 **71 × 98 mm**（4"×6" 相纸对折当封面，实测每半可用 71；切完 68），**9 pt 宋体，18 字 × 15 行**，spread 1.4 → 行距 15.12 pt = **1.68 字**；版心 57.15 × 91.8 mm，约 270 字 / 页；订口 5 mm、上 7.5 mm、页脚 6.5 mm、切口 8.85 mm。密排档 `dense` = 7.5 pt **黑体**，23 字 × 18 行，spread 1.45（「喷墨机上 8pt 以下的宋体横笔会糊」所以连字体一起换）。
- **mini 开本（搁置）**：内页 **99 × 148 mm**（≈ A6；相纸不折），9 pt，**25 字 × 24 行**，spread 1.4，约 600 字 / 页。搁置原因 = 两张相纸之间没有书脊。
- 装订：16 页一贴（骑马钉）、多贴用布基胶带粘书脊；前后各一张环衬；`tools/impose.py` 拼到 Letter（平订切叠 / `--fold` 骑马钉）；电子书 = 同一页面尺寸加封面封底。
