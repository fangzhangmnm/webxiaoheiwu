## 0.3 范围（两刀一起切）

1. **无地骑士对齐**（参照 WeebPaint `ai-docs/20260827-p3-gallery-multiinstance-grill-verdicts.md` + `_isLazyBlankSession`）
   - 进 app = 一篇**懒空白新稿**（lazy blank）：不落笔不落盘、不进列表、不推云；第一笔才物化（起名 `yyyymmdd-hex4`；用户顶栏给了文件名就用那个——ADR-0007 起没有标题框）。
   - 锁着的加密稿 / 不可用稿：**编辑器不撒谎**——不再用空 textarea 冒充「打开了」；要么解锁后才进编辑器，要么停在懒空白稿 + 列表里那篇标锁。现状 `st.unavailable`/`st.locked` 的空面板即「UI 撒谎」。
   - **无 store 也是合法编辑器**：没登录、没库、隐私窗口——照样能写，本地草稿语义（WeebPaint 无地 = 除云外全功能，[[feedback_localfile_full_features]]）。
2. **连接别的库**（WeebPaint P3 那套）：folder provider（File System Access，桌面）+ 多库 registry + 图库头的库切换；OneDrive 仍是 appfolder 唯一云（硬规则 #6/#7）。store 侧 `@internal/store` 0.5.0 folder provider 已有，app 侧 registry 抄 WeebPaint `gallery-shell`。

## 所见即所得纪元（2026-09-04 user 拍板方向；序号待定，在 0.3 之后）

> 用户原话（2026-09-04）：「我自己的话其实用 latex，codeblock 还蛮顺手的，这个 lift 之前的纪律，但是进以后契约。然后排版统一。嗯我是想用所见即所得。纯文本的问题是 anti abandonware 的话我对任何 hidden convention 过敏。但是写作的话确实有个标题会有意思。」

- **方向**：所见即所得（contenteditable 一类），不是「源码模式 + 排版视图」。落盘 = **标准 markdown**（公开方言不是私约定 → anti-abandonware 成立）；**标题 = `# ` 第一行**（ADR-0007 只把文件名降格，标题留给这里）。
- **契约要钉进 ADR**：方言（CommonMark + GFM 表格 + fenced code + `$…$` 数学的 Pandoc/GitHub 事实方言）、扩展名（新稿 `.md`，旧 `.txt` 照旧当纯文本；`crypt.ext` 跟着）、字数统计跳过标记、中文排版（斜体在 CJK 是假斜体 → `*强调*` 渲成着重号 `text-emphasis`；粗体照常）。
- **成本（minor 纪元）**：编辑器核心换掉 → RIME 接入（`ime.ts` / `text-edit.ts` undo 深模块全长在 textarea 上）与 Quest/iOS 的 contenteditable 坑要重做；家族里**没有**任何现成 markdown / KaTeX / 编辑器库可复用，都要新 vendor（KaTeX 含字体体积大，开工前 grill）。
- **顺势并入**：列表解锁后显真标题的 peek 增强（store 加 `RawFile.readPeek`，只取 `# ` 那一行；每篇一次 PBKDF2，Quest 上 0.3–1 s/篇，后台跑、内存缓存、明文标题不落 IDB）。
- 不动：加密容器 / 密码模型（ADR-0002/0005）、命名（ADR-0007）。
