# 换稿的审稿探针

> created 2026-11-10 by Claude Fable 5.2（审 v3.0.18 换稿修时写的；审稿 = 家族根 `ai-docs/20261110-review-wxhw-open-swap-fix.md`）。as-of v3.0.18。

不在任何测试命令里，手动跑：在仓目录里 `node probe/open-swap/<文件>`。用的是端到端同步测试的架子（真 app + 真库 + 真 IndexedDB，网盘是内存里的假网盘），无头。

| 文件 | 测什么 | v3.0.17 | v3.0.18 |
|---|---|---|---|
| `cross-mode.mjs` | 文本稿和书抢同一个编辑框（函数级，两次换稿叠在一起）：P1 文本稿读得慢、接着开书；P2 书读得慢、接着开文本稿 | 红 | 红（v3.0.19 要修的） |
| `boot-race.mjs` | 冷启动：这台上次开的是书（读 4 秒），别的设备最后写的是文本稿（已收进「换稿 ⑨」） | 红 | 绿 |
| `ui-clicks.mjs` | 第二台设备在书库里真点击连点两张卡片：第二下被「正在检查云端…」的整屏锁挡住 | — | 挡住 |
| `extra.mjs` | T1 存不上也另存不了 → 不换稿；T2 存不上、另存能成 → 留底后换稿；T3 连点两篇（三条都已收进 `npm run e2e:sync`「换稿 ⑩⑪⑫」） | 红 | 绿 |
| `boot-fail.mjs` | 冷启动时上次那篇读的时候网盘报 500：库自己退回读本机那份，稿照常能开能写 | 绿 | 绿 |

「红」= 脚本打印的 ✗。脚本自己总是以 0 退出，看输出。
